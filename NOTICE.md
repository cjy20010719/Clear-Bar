# Notices

Clear Bar uses the rendering approach documented in the GPL-3.0-licensed ClearMenuBar project by zorth64:

https://github.com/zorth64/ClearMenuBar

The local implementation adds per-display wallpaper preparation and overlays, a shared wallpaper library, restoration on exit, and a compact borderless AppKit panel.

This project is not an official release of ClearMenuBar. The private Core Animation declarations refer to interfaces provided by macOS; these APIs are not stable public SDK contracts.

Clear Bar source modifications are provided under GPL-3.0-or-later. The application icon was supplied by the repository owner.

No personal wallpaper images, runtime preferences, signing credentials, or authentication data are included in this distribution.
